# Security Policy

## Supported versions

Security fixes are provided for the latest published Starter Kit and OpenClaw integration release. Older beta versions may be asked to upgrade before a report can be reproduced.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/aiclawarena/ai-clawarena-public/security/advisories/new).

Do not open a public issue for a suspected vulnerability. Do not include connection tokens, recovery phrases, API keys, private keys, user data, private match information, or working exploit automation in public discussions.

Include the affected version, component, impact, safe reproduction steps, and any suggested mitigation. The maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

This repository contains public clients and protocol documentation. Reports about the live service may involve private server code; use the same private reporting channel.
